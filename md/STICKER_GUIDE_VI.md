## ❓ CÂU HỎI THƯỜNG GẶP

### Q: Recent stickers có mất khi tắt trình duyệt không?
**A**: Không, chúng được lưu vĩnh viễn trong localStorage. Chỉ mất khi bạn xóa cache trình duyệt.

### Q: Recent stickers có đồng bộ giữa các thiết bị không?
**A**: Không, mỗi thiết bị/trình duyệt có Recent riêng.

### Q: Tối đa bao nhiêu stickers trong Recent?
**A**: 30 stickers. Khi thêm sticker thứ 31, sticker cũ nhất sẽ tự động bị xóa.

### Q: Tại sao tìm không thấy sticker?
**A**: 
- Từ khóa có thể không đúng
- Sticker có thể không tồn tại trên Zalo
- Thử từ khóa khác hoặc tiếng Anh

### Q: Recent stickers bị mất hết?
**A**: 
- Kiểm tra localStorage của trình duyệt
- Có thể do xóa cache hoặc incognito mode
- Gửi sticker mới để tạo lại Recent

### Q: Làm sao backup Recent stickers?
**A**: 
```javascript
// Mở Console (F12) và gõ:
localStorage.getItem('zalo_recent_stickers')
// Copy kết quả ra file text

// Restore:
localStorage.setItem('zalo_recent_stickers', '<paste kết quả>')
```

## 🐛 LỖI THƯỜNG GẶP

### Lỗi 1: Sticker không hiện trong Recent

**Nguyên nhân**: localStorage bị disabled hoặc đầy

**Cách sửa**:
1. Mở F12 → Console
2. Gõ: `localStorage.getItem('zalo_recent_stickers')`
3. Nếu lỗi → localStorage bị disabled
4. Enable localStorage trong browser settings

### Lỗi 2: Tìm Zalo sticker bị lỗi

**Nguyên nhân**: Chưa đăng nhập Zalo hoặc API lỗi

**Cách sửa**:
1. Kiểm tra đã đăng nhập Zalo chưa
2. F5 refresh page
3. Logout → Login lại
4. Xem Console có lỗi API không

### Lỗi 3: Sticker không gửi được

**Nguyên nhân**: Kết nối Zalo lỗi

**Cách sửa**:
1. Kiểm tra kết nối internet
2. F5 refresh
3. Logout → Login Zalo lại
4. Thử gửi text trước, nếu OK → Thử sticker
